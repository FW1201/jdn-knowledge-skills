# 簡明技術中文（Plain Technical Chinese, PTC）

> 參考 ASD-STE100（Simplified Technical English，航太維修文件用的受控語言）的精神，改寫為適合繁體中文的寫作規範。
> ASD-STE100 本身只規範英文；本文件不是它的翻譯，而是借用其原則。
> 使用時可依情境放寬，例如「80% PTC」：保留句長與一句一事，其餘從寬。

## 一、句子

| # | 規則 | 上限／說明 |
|---|---|---|
| S1 | 一句只講一件事 | 出現第二個動作就拆句 |
| S2 | 程序句（指示怎麼做） | ≤ 30 字，用祈使句開頭：「開啟…」「確認…」 |
| S3 | 描述句（說明是什麼） | ≤ 40 字 |
| S4 | 段落 | ≤ 5 句；只談一個主題 |
| S5 | 主動語態 | 寫「系統更新索引」，不寫「索引被系統更新」 |
| S6 | 條件先講 | 「若 X，則 Y」：條件放句首，動作放句尾 |
| S7 | 警告先講 | 「⚠ 注意：…」放在相關步驟**之前** |

## 二、用詞

| # | 規則 | 例 |
|---|---|---|
| W1 | 一個術語只用一種說法 | 定了「頁面」就不再混用「條目」「文章」 |
| W2 | 用常用詞，不用文言或公文腔 | 「開始」不用「肇始」；「之前」不用「之際前」 |
| W3 | 刪除空泛修飾 | 刪「非常」「相當」「有效地」「全面性地」 |
| W4 | 數字用阿拉伯數字＋單位 | 「3 頁」「30 字」 |
| W5 | 英文術語第一次出現時附中文 | 「frontmatter（檔頭欄位）」 |
| W6 | 不用代名詞指涉跨句的對象 | 重複名詞，不寫「它」「此」「該」 |

## 三、結構

| # | 規則 |
|---|---|
| T1 | 步驟用編號清單，一步一個動作 |
| T2 | 並列 ≥ 3 項就用清單或表格，不寫成長句 |
| T3 | 結論先講，理由後講 |
| T4 | 每段第一句就是該段重點 |

## 四、改寫示範

**原文**（59 字，三件事混在一句）：
> 在進行入庫作業之前，建議使用者應當先行確認 index.md 是否已經被正確地更新，以避免可能產生的重複頁面問題。

**PTC**：
> ⚠ 注意：重複頁面會造成連結錯亂。
> 1. 開啟 `wiki/index.md`。
> 2. 確認新素材不在清單中。
> 3. 開始入庫。
